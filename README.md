
# Potato

Bienvenue dans notre jeu, Potato et Le Royaume Infesté.

Le but du jeu est simple, vous incarnez un personnage qui devra survivre à des vagues d'ennemis de plus en plus puissantes.

À chaque vague les ennemis auront plus de vie et feront plus de dégâts.
Pour vous permettre de survivre le plus longtemps possible, vous pourrez, après chaque fin de vague améliorer votre personnage.

    


## Installation

-Avec l'exécutable disponible [ici](https://github.com/quentinpags/POO_Project1/releases/latest)

## Cloner le projet

    git clone <URL_DU_DEPOT>
    pip install -r requirements.txt

## Commandes

    ZQSD pour se déplacer 
    Barre espace pour attaquer (visee attaque dans le sens ou on va)
    U pour changer d'arme
    M pour attaquer avec la barre espace
    touche directionnelles pour viser avec les armes
